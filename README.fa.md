# ربات فروش VPN تلگرام

**فارسی** | [English](README.md)

یک ربات فارسی برای فروش اشتراک VPN که لوکیشن‌ها، پروتکل‌ها، پلن‌ها، قیمت‌ها و روش تحویل آن از داخل پنل ادمین تلگرام مدیریت می‌شود.

## امکانات

- ساخت کشور و مولتی‌لوکیشن با نام و ایموجی دلخواه
- پشتیبانی از لینک اشتراک، WireGuard و OpenVPN
- پلن‌های یک‌ماهه و دوماهه
- پرداخت کارت‌به‌کارت و کیف پول
- چرخش خودکار بین چند کارت بانکی
- تحویل دستی، موجودی آماده و اتصال اختیاری به 3x-ui
- مدیریت ادمین‌ها، کاربران، رسیدها و آموزش‌ها
- نام برند و پیام‌های قابل تغییر

## نصب سریع

پیش‌نیازها: سرور Linux، پایتون 3.11 یا جدیدتر و دسترسی به تلگرام و PyPI.

```bash
git clone https://github.com/danadoago92-coder/vpn-bot.git
cd vpn-bot
bash install.sh
bash run.sh
```

نصاب توکن ربات، آیدی عددی ادمین، نام برند، اطلاعات پرداخت، آیدی پشتیبانی، پروکسی تلگرام و تنظیمات اختیاری 3x-ui را از شما می‌گیرد.

## اجرای دائمی

```bash
sudo bash install.sh --systemd --target /opt/vpn-bot
```

دستورهای مدیریت سرویس:

```bash
sudo systemctl status vpn-bot
sudo systemctl restart vpn-bot
sudo journalctl -u vpn-bot -n 50 --no-pager
```

## راه‌اندازی فروشگاه

دستور `/admin` را برای ربات بفرستید و سپس:

1. وارد بخش «لوکیشن‌ها و پروتکل‌ها» شوید.
2. یک کشور یا مولتی‌لوکیشن با نام و ایموجی دلخواه بسازید.
3. پروتکل‌های قابل فروش آن لوکیشن را روشن کنید.
4. از بخش «مدیریت پلن‌ها» قیمت، حجم و مدت سرویس‌ها را بسازید.
5. روش تحویل دستی، موجودی آماده یا خودکار را انتخاب کنید.

نصب تازه هیچ کشور، پلن یا اطلاعات مشتری آماده‌ای ندارد.

## روش‌های تحویل

- **دستی:** بعد از تأیید پرداخت، ادمین لینک یا فایل کانفیگ را می‌فرستد.
- **موجودی آماده:** لینک‌های از قبل ثبت‌شده، یکی‌یکی تحویل مشتری می‌شوند.
- **خودکار:** ربات کانفیگ عادی را از طریق 3x-ui می‌سازد و ارسال می‌کند.

برای WireGuard فایل `.conf` و برای OpenVPN فایل `.ovpn` قابل ارسال است. ساخت خودکار 3x-ui در نسخه فعلی برای پلن‌های لینک اشتراک استفاده می‌شود.

## فایل‌های خصوصی

این فایل‌ها هنگام نصب یا اولین اجرا ساخته می‌شوند:

- `.env` برای توکن و تنظیمات خصوصی
- `admins.json` برای آیدی مدیرها
- `data/bot.sqlite3` برای کاربران، سفارش‌ها، پلن‌ها و سرویس‌ها
- `backups/` برای نسخه‌های پشتیبان

این فایل‌ها توسط Git نادیده گرفته می‌شوند و نباید در GitHub آپلود شوند.
